The embedding layer is a lookup table with one row per vocabulary entry and
one column per dimension of the model's internal width — `d_model`, anywhere
from 768 in small models to 16k+ in large ones.

Token id 9388 goes in, row 9388 comes out: a vector of `d_model` floats. That
is the entire operation. No arithmetic beyond indexing — and yet this table
holds a meaningful fraction of the model's total parameters, and it is
learned, end to end, like everything else.

## What the vector means

After training, the geometry of the table is not arbitrary. Tokens that are
used similarly land near each other; directions in the space pick up
consistent interpretations. The table is where "cat" first becomes something
the machine can compute with — a point in a space where distance and
direction carry usage.

Don't over-read the classic `king − man + woman ≈ queen` trick. It works
often enough to be famous and fails often enough to be a poor mental model of
what the vector is for. The vector is not a definition of the word. It is a
starting position — one that the blocks above will rewrite beyond
recognition.

## Position is added, not inherent

A row of the table knows nothing about where its token sits in the sentence.
"the cat sat" and "sat cat the" would produce the same four vectors in a
different order, and nothing downstream would ever notice.

So a position signal is added to each vector — a second vector that encodes
"this is position 3". Older models add a sinusoidal or learned position
embedding here; most modern ones use rotary encodings (RoPE) applied inside
attention instead. Either way, the effect is the same: each column of numbers
now carries *what* the token is and *where* it sits.

## The residual stream begins

These position-tagged vectors are the first state of what is best understood
as a conveyor belt: one vector per token position, flowing upward through
every block. Each block reads the belt, computes something, and *adds* its
contribution back — it never overwrites.

That one design choice, the residual connection, is why a 96-layer model can
be trained at all. The vector that enters block one is still recognisably
inside the vector that leaves the last block — buried under dozens of added
refinements, but never destroyed. The blocks don't replace the signal. They
annotate it.
